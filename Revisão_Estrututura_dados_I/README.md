## Código fonte em linguagem C++ de implementação de Recursividade

Este código calcula a soma de todos os números inteiros de 1 até o número informado, usando duas formas: laço for e recursão.

- SomaAntecessoresNormal(int valor): usa um for para somar 1 + 2 + 3 + ... + valor.
- SomaAntecessoresRecursiva(int valor): faz a mesma soma, mas chamando a própria função com valor - 1 até chegar em 1.
- No main, o programa pede um número ao usuário e mostra os dois resultados.

Por exemplo, se o usuário digitar 5:
1 + 2 + 3 + 4 + 5 = 15.
